# Тесты сервисов

Юнит-тесты бизнес-логики с использованием моков.

## Классы

### CardServiceLogicTest
Тесты для проверки логики работы с картами.

**Методы:**

1. `blockCard_ShouldChangeStatusToBlocked()` - проверка изменения статуса карты при блокировке.

2. `blockCard_ShouldThrow_WhenAlreadyBlocked()` - проверка выбрасывания исключения при попытке заблокировать уже заблокированную карту.

3. `checkBalance_ShouldReturnCorrectValue()` - проверка корректности возвращаемого баланса.

**Что тестируется:**

1. Изменение статуса карты с `ACTIVE` на `BLOCKED`

2. Обработка исключений при повторной блокировке

3. Корректность хранения и получения баланса

### TransferServiceLogicTest
Тесты для проверки логики переводов между картами.

**Методы:**

1. `transfer_ShouldSubtractFromFromCardAndAddToToCard()` - проверка корректного списания с карты отправителя и зачисления на карту получателя.

2. `transfer_ShouldNotChangeTotalSum()` - проверка сохранения общей суммы средств (баланс отправителя + баланс получателя) после перевода.

3. `transfer_ShouldThrow_WhenFromCardBlocked()` - проверка выбрасывания исключения при попытке перевода с заблокированной карты.

4. `transfer_ShouldThrow_WhenInsufficientFunds()` - проверка выбрасывания исключения при недостаточном балансе.

5. `transfer_ShouldThrow_WhenCardsBelongToDifferentUsers()` - проверка выбрасывания исключения при попытке перевода между картами разных пользователей.

**Что тестируется:**

1. Математическая корректность перевода

2. Сохранение суммы на обеих картах

3. Проверка статуса карт

4. Проверка достаточности средств

5. Проверка принадлежности карт одному пользователю

### UserServiceLogicTest
Тесты для проверки логики работы с пользователями и ролями.

**Методы:**

1. `hasRole_ShouldReturnTrue_WhenUserHasRole()` - проверка определения наличия роли у пользователя.

2. `hasRole_ShouldReturnFalse_WhenUserDoesNotHaveRole()` - проверка определения отсутствия роли у пользователя.

3. `addRole_ShouldAddRole_WhenNotPresent()` - проверка добавления новой роли пользователю.

4. `removeRole_ShouldRemoveRole_WhenPresent()` - проверка удаления роли у пользователя.

**Что тестируется:**

1. Проверка наличия ролей у пользователя

2. Добавление новых ролей

3. Удаление существующих ролей

4. Корректность работы со списком ролей
