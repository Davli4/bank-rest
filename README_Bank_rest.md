# Система управления банковскими картами
## Описание проекта
RESTful API сервис для управления банковскими картами с поддержкой JWT аутентификации и ролевой модели (ADMIN/USER). Проект разработан в соответствии с техническим заданием и предоставляет полный функционал для административного управления и пользовательских операций с картами.

### Технологический стек
1. Java 17

2. Spring Boot 3.1.5

3. Spring Security + JWT (аутентификация и авторизация)

4. Spring Data JPA (работа с базой данных)

5. PostgreSQL 15 (основная БД)

6. H2 Database (для тестирования)

7. Liquibase (миграции БД)

8. Docker / Docker Compose

9. OpenAPI (Swagger) (документация API)

10. Maven (сборка проекта)

11. Lombok 

12. JUnit 5 / Mockito (тестирование)

### Функциональность
**Администратор:**

1. Создание, блокировка, активация, удаление карт

2. Управление пользователями (назначение ролей, деактивация)

3. Просмотр всех карт с фильтрацией (по пользователю, статусу, владельцу)

4. Статистика системы

**Пользователь:**
1. Просмотр своих карт (пагинация + фильтр по статусу)

2. Запрос блокировки карты

3. Переводы между своими картами

4. Просмотр баланса

5. Просмотр профиля

## Запуск проекта
### Предварительные требования

1. Docker и Docker Compose

2. Java 17+

3. Maven

### Локальный запуск (без Docker)

```
# Запустить PostgreSQL
docker-compose up -d postgres

# Собрать проект
mvn clean package -DskipTests

# Запустить приложение
mvn spring-boot:run
```

### Запуск через Docker
```
# Собрать проект
mvn clean package -DskipTests

# Запустить все сервисы
docker-compose up -d --build

# Просмотр логов
docker-compose logs -f ap
```

Приложение будет доступно по адресу: `http://localhost:8080`

### API Документация
После запуска приложения документация доступна в **Swagger UI**:

**Swagger UI**: `http://localhost:8080/swagger-ui.html`

**OpenAPI JSON**: `http://localhost:8080/api-docs`

## Основные эндпоинты
### Аутентификация (/api/auth)

`POST /login` - Вход в систему (получение JWT токена)

Пользователь `(/api/users)`

`GET /profile` - Профиль текущего пользователя

`GET /cards `- Свои карты (с пагинацией)

`GET /cards/{id}` - Детали карты

`GET /cards/{id}/balance` - Баланс карты

`GET /cards/status/{status}` - Фильтр по статусу

`POST /cards/{id}/block` - Заблокировать свою карту

`POST /transfer` - Перевод между своими картами

Администратор `(/api/admin)`

`GET /users` - Все пользователи

`PUT /users/{id}/role` - Назначить админа

`DELETE /users/{id}/deactivate` - Деактивировать пользователя

`GET /cards` - Все карты (с фильтрами)

`POST /cards` - Создать карту пользователю

`PUT /cards/{id}/block` - Заблокировать карту

`PUT /cards/{id}/activate` - Активировать карту

`DELETE /cards/{id}` - Удалить карту

`GET /stats` - Статистика системы

### Тестирование

```
# Запуск всех тестов
mvn test
```

### Покрытие тестов

1. **Util-классы**: 100% (маскировка, валидация)

2. **Сервисы**: 90% (логика переводов, управления картами)

3. **Контроллеры**: 80% (интеграционные тесты)

### Безопасность

1. JWT токены для аутентификации (HS256)

2. Ролевая модель: ADMIN / USER

3. PasswordEncoder: BCrypt

4. Маскирование номеров карт при выводе пользователю

### Валидация входных данных

**База данных** PostgreSQL 15

Миграции: Liquibase (автоматическое применение при старте)

Схема: `users`, `roles`, `user_roles`, `cards`
